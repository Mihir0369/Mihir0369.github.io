02 / How I work

Useful analysis starts
before the dashboard.

A clear process builds confidence that the analysis can be maintained, explained and used.

01 / DEFINE

Start from the decision

Turn the question into explicit measures and say what a useful answer should help someone do next.

02 / VALIDATE

Make the numbers trustworthy

Check completeness, reconcile totals, document data quality issues and state what the source cannot tell you.

03 / DELIVER

Build it to be reused

SQL, Python, Power Query, a star-schema model and documented DAX, all in version control.
